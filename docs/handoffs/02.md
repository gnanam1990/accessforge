## Cross-language agreement

Twelve shared vectors are validated by both suites, and a differential test executes both
implementations over fifteen further payloads — every C0 control character, astral-plane
characters, combining sequences, empty keys and safe-integer boundaries. The TypeScript suite also
recomputes the digest of each schema document, so the two languages are shown to agree on the
contracts themselves, not only on test payloads.

That differential test **fails rather than skips** when the TypeScript build is missing.

## Defect found by property testing

`cancel()` decided the cancelled outcome from the status (`is QUEUED`) rather than from whether
execution had begun. A run that reached LEASED and admitted no action was therefore finalized
CANCELLED/INCONCLUSIVE, which CONTRACTS section 5 forbids — before any admitted execution the
outcome is NOT_EVALUATED.

Found by `test_no_event_sequence_produces_an_inadmissible_state` on the sequence
`progress → request_cancel → acknowledge → cancel`; no hand-written test covered it. Fixed by
separating the two questions the code had conflated: whether a stop acknowledgement is required
(yes from LEASED onward, because a runner holds the desktop) and which outcome applies (keyed on
execution, not status). A named regression test now covers it, and reverting the fix fails two
tests.

## Deliberate restrictions

Non-integral floats and unsafe integers are **rejected** by both canonicalizers rather than
formatted, so there is nowhere in a canonical document for a confidence score to live and
`outcome-record.schema.json` provides no field for one. Rationale in ADR 0003.

## Unresolved design questions

1. **Full ES6 float formatting** is deferred, not solved. If a future contract genuinely needs
   fractional numbers, it needs its own shared vectors before either implementation accepts one.
2. **Schema packaging.** `SCHEMA_DIR` resolves relative to the source tree, which works for the
   editable workspace install but not for a built wheel. Module 18 owns distribution and should
   package the schemas as package data.
3. **Evidence-envelope payload variants** are typed loosely today: the envelope requires producer
   provenance, but per-event-type payload shapes are not yet constrained. Module 10 owns ingestion
   and should tighten them alongside the sequencer.
