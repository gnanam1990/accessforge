## Cross-language agreement

Twelve shared vectors are validated by both suites, and a differential test executes both
implementations over fifteen further payloads — every C0 control character, astral-plane
characters, combining sequences, empty keys and safe-integer boundaries. The TypeScript suite also
recomputes the digest of each schema document, so the two languages are shown to agree on the
contracts themselves, not only on test payloads.

That differential test **fails rather than skips** when the TypeScript build is missing.

## Defect found by property testing

`cancel()` decided the cancelled outcome from the status (`is QUEUED`) rather than from whether
execution had begun. A run that reached LEASED and admitted no action was therefore finalized
CANCELLED/INCONCLUSIVE, which CONTRACTS section 5 forbids — before any admitted execution the
outcome is NOT_EVALUATED.

Found by `test_no_event_sequence_produces_an_inadmissible_state` on the sequence
`progress → request_cancel → acknowledge → cancel`; no hand-written test covered it. Fixed by
separating the two questions the code had conflated: whether a stop acknowledgement is required
(yes from LEASED onward, because a runner holds the desktop) and which outcome applies (keyed on
execution, not status). A named regression test now covers it, and reverting the fix fails two
tests.

## Independent review findings and closure

A separate reviewing agent reviewed `23fe6c8..8fe3846` read-only. It had no code-execution tool and
labelled both findings as reasoned rather than reproduced; both were then reproduced by execution
here, and both were real.

| # | Finding | Severity | Status |
|---|---|---|---|
| 1 | Lone surrogates diverge between the two canonicalizers | Critical | FIXED WITH PROOF |
| 2 | RFC3339 expiry compared as text, failing open | Important | FIXED WITH PROOF |

**Finding 1.** For `{"s": "\ud800"}`, Python raised a raw `UnicodeEncodeError` from inside
`digest()` — not even the module's own error type — while TypeScript **silently substituted U+FFFD
and returned a successful digest**, byte-identical to hashing the replacement character. Confirmed
by execution in both languages. The TypeScript behaviour is the more dangerous: a confident, wrong
hash with no signal, in the one function every digest-bound guarantee depends on.

Both implementations now detect unpaired surrogates and raise their domain error, in string values
and in object keys. Keys are checked *before* sorting, because the sort key is itself an encoding
and raised first. Valid surrogate pairs are unaffected, with an allowed-path control asserting
emoji still work. Three rejection rules were added to the shared vectors, and the differential
harness now drives both languages over these inputs.

**Finding 2.** Expiry compared RFC3339 strings lexicographically. Given
`expires_at = "2026-09-09T12:00:00Z"` and `now = "2026-09-09T12:00:00.000001Z"` — one microsecond
later, both valid under the `rfc3339Utc` pattern — the strings first differ at `.` (0x2E) versus
`Z` (0x5A), so `now >= expires_at` is **False** and an expired approval was **accepted**. Confirmed
by execution: an approval expired by one microsecond passed `check()`.

This was reachable from ordinary code: `datetime.now(UTC).isoformat()` emits the fractional part
only when microseconds are non-zero, so any service mixing it with a whole-second timestamp hits
this intermittently. Fixed by parsing both sides in a new `timestamps` module, which also validates
format at dataclass construction — the domain package defends its own invariant rather than
trusting upstream schema validation, since it can be constructed directly.

New mutation checks confirm both fixes are load-bearing: removing the surrogate check fails 7
tests; reverting expiry to string comparison fails 5.

## Deliberate restrictions

Non-integral floats and unsafe integers are **rejected** by both canonicalizers rather than
formatted, so there is nowhere in a canonical document for a confidence score to live and
`outcome-record.schema.json` provides no field for one. Rationale in ADR 0003.

## Unresolved design questions

1. **Full ES6 float formatting** is deferred, not solved. If a future contract genuinely needs
   fractional numbers, it needs its own shared vectors before either implementation accepts one.
2. **Schema packaging.** `SCHEMA_DIR` resolves relative to the source tree, which works for the
   editable workspace install but not for a built wheel. Module 18 owns distribution and should
   package the schemas as package data.
3. **Evidence-envelope payload variants** are typed loosely today: the envelope requires producer
   provenance, but per-event-type payload shapes are not yet constrained. Module 10 owns ingestion
   and should tighten them alongside the sequencer.
