## Real platform evidence

**No actual-reader smoke probe was run**, and this handoff makes no actual-AT claim. Module 00
authorises a probe only where the capability is "already configured"; it is not, and launching
VoiceOver would have spoken aloud on the owner's active desktop and required enabling the very
setting under assessment. Attempted / unavailable / failed / observed are distinct states, and this
capability is **unavailable**, not failed and not observed.

A correction is recorded rather than hidden: the first VoiceOver probe in this session checked only
the legacy preferences path, which is wrong for macOS 26.6. It was re-probed at the Sequoia+
sandboxed path; both commands and both results appear in `docs/capabilities.md` §5.1.
