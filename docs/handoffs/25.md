## Delivered reporting command

```sh
uv run python scripts/benchmark_report.py \
  --plan /private/operator/benchmark-plan.json \
  --results /private/operator/benchmark-results.json
```

The command reads bounded JSON inputs and prints a JSON report. It starts no
service, reader, model, browser or mutation process. Invalid inputs produce a
generic diagnostic without echoing private data. Keep the operator-owned plan,
answer keys and report outside both navigator access and the patchable source
tree. Freeze and independently retain the plan before execution.

The plan has exactly these fields:

- `corpusVersion`: bounded version identifier.
- `identity`: `sourceCommit` (40 lowercase hex), `buildDigest`,
  `profileDigest`, `evaluatorDigest`, `lockfileDigest` (64 lowercase hex),
  `evidenceClass`, and a nonempty `versions` mapping of bounded identifiers.
- `cases`: unique `caseId`, `category`, `repetitions` (1–100), and
  independently protected `oracleDigest` (64 lowercase hex).

Categories are CLEAN, INJECTED_DEFECT, EXTERNAL_DEFECT, UNSUPPORTED and
INFRA_FAILURE. Evidence classes are UNIT, CONTRACT, LOCAL_INTEGRATION,
ACTUAL_AT, ACTUAL_MODEL, HUMAN_REVIEW and OPERATIONS. Each report uses one
exact identity/class cohort; produce separate reports for different proof
levels and platforms. Combining reports does not prove combined acceptance.

The results object has only `observations`. Each observation includes its
`caseId`, `repetition`, matching full `identity` and `status`.
COMPLETED requires `outcome` (PASS/FAIL/INCONCLUSIVE), `bundleDigest` and
`durationMs`. BLOCKED/TIMED_OUT require `reasonCode` and no verdict.
Optional fields are `bundleDigest`, `durationMs` and `reasonCode` as
appropriate. Never put secrets or free-form transcripts in these inputs.

Every planned repetition appears in output, including inferred NOT_RUN rows.
Duplicate slots, reused bundle digests, unplanned cases, excess repetitions,
mixed identities, nonfinite durations and unknown fields are refused. All five
categories appear, including zero denominators. Reports retain supplied
failures and separate false defects on clean controls, false passes on known
defects, unsupported conclusive verdicts, timeouts and inconclusive outcomes.
No global accuracy percentage is calculated.

## Trust boundary

The output kind is DECLARED_BENCHMARK_ACCOUNTING_NOT_EVIDENCE_VERIFICATION;
`evidenceVerified` is always false. A supplied bundle digest is a reference,
not proof of its contents, signature, provenance or independent execution.
Distinct digests do not prove independent repetitions. Oracle labels, exact
versions and pre-execution freezing require separate independent evidence.
The plan digest hashes normalized sorted-key JSON for inventory purposes; it
is not an RFC8785 run-manifest digest, signature or qualification attestation.
