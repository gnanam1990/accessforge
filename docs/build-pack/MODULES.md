# AccessForge Tester Desk · module index

These are dependency-ordered work units. Once a contract is agreed, UI, adapter and test contributors may proceed on fixtures matching that contract and integrate against its real implementation before acceptance.

1. [M01 · Commission and task contracts](prompts/M01.md) — Implement versioned commission authoring with environment, journey, fee and deliverable rubric pinned at publication. Bind each accepted assignment to its exact immutable brief revision.
2. [M02 · Tester eligibility and consent](prompts/M02.md) — Implement restricted enrollment, conflicts, scoped visibility, offer expiry and atomic assignment claims.
3. [M03 · Accessible evidence capture](prompts/M03.md) — Build keyboard and reader-friendly drafts, step outcomes, permitted attachments and digest-backed uploads.
4. [M04 · Submission and review](prompts/M04.md) — Seal revisions, validate completeness against the rubric, separate task outcome from evidence acceptance, and allow justified revision requests.
5. [M05 · Compensation and reconciliation](prompts/M05.md) — Create the payable exactly once, implement an approved compensation adapter and reconcile uncertain results.
6. [M06 · Client reporting and privacy](prompts/M06.md) — Project only consented evidence to a client report and implement redaction and retention operations.
7. [M07 · Retest and release comparison](prompts/M07.md) — Link follow-up commissions by defect and compare only matching task and environment dimensions.
8. [M08 · End-to-end agency pilot](prompts/M08.md) — Exercise a real test browser, a consenting independent tester and an agency reviewer with a restart and a redacted evidence export.
